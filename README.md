# FindIT — College Lost & Found Management System

FindIT is a comprehensive Lost and Found management platform designed for college campuses.

## Modules
- **Member 1**: Authentication, User Management, Lost & Found Reports, Dashboard.
- **Member 2**: Intelligent Matching Engine, Private Claim Verification, Weighted Scoring, Candidate Ranking, Signal Breakdown.
- **Member 3**: Admin Handover, Return Audit, Approval Workflows.

## Tech Stack
- Backend: Python Flask, SQLAlchemy, SQLite, scikit-learn, NumPy, Pillow
- Testing: pytest
